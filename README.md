# MAX — Jax_Morph

A JAX implementation of the Morph approximation for Bayesian inference.

This repository will host the development of Jax_Morph, with an initial focus on density approximation from posterior samples and Bayesian evidence estimation.

## Status

Early development. The implementation, installation instructions, examples, and benchmarks will be added as development progresses.

## Planned scope

- JAX-compatible density estimation and sampling.
- Morph-based Bayesian evidence estimation.
- Numerical validation against problems with known evidence.
- Benchmarks for accuracy and computational efficiency.
